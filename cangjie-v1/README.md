# Cangjie 库索引

本目录收录来自仓颉中心仓 (cjpm) 的 Cangjie 库索引，按包组织：

- 大版本目录：`cangjie-v1`
- 包路径：`<group>/<name>/<name>.md`
- 收录来源：`pkg.cangjie-lang.cn` 中心仓 API
- 当前共收录 693 个 Cangjie 包。

## 数据源

- 中心仓：https://pkg.cangjie-lang.cn/
- 文档：https://cangjie-lang.cn/docs
- cjpm 包管理器：仓颉官方
