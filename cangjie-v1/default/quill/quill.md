# quill

**Tag**: ui

## 简介

quill — a pure-Cangjie retained-mode terminal UI framework: 12 widgets, CJK wide chars, truecolor, mouse, pulsar-driven dirty-region rendering, alt-screen, focus routing. Depends on pulsar (reactive state).
