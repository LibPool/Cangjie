# governor4cj

**Tag**: testing, serialization, crypto

## 简介

governor4cj: 仓颉语言速率限制库，Rust governor (GCRA 算法) 的移植实现。提供 per-second / per-minute / per-hour / per-day 配额、突发容量、泛型键控限流 KeyedRateLimiter<K>、分片并发存储 DashMapStateStore、自定义哈希器 KeyHasher、文件持久化 FileStateStore、JSON 序列化、限速迭代器 RateLimitedIterator、Quanta 时钟与多线程原子状态。
