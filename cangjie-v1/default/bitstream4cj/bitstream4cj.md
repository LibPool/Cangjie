# bitstream4cj

**Tag**: library

## 简介

Bit-level stream reader/writer for Cangjie: arbitrary-width bit fields, MSB/LSB-first bit order, byte alignment, unary and Exp-Golomb (H.264 ue/se) coding, exhaustively round-trip verified
