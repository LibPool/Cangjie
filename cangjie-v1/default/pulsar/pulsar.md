# pulsar

**Tag**: library

## 简介

Pulsar — a minimal reactive kernel for Cangjie: flat-subscriber Signal<T>, lazy Memo<T>, deferred batching. No dependency graph, no executor. Thread-safe write path (set/update from any thread); drain/subscribe/Memo on the host thread.
