# bytes4cj

**Tag**: library

## 简介

高效字节缓冲区库：提供不可变字节序列 Bytes 与可增长缓冲区 BytesMut，参考 tokio-rs/bytes 设计，适配仓颉语言。支持切片/拆分零拷贝视图、数值类型字节序读写（Buf/BufMut trait）与迭代器。
