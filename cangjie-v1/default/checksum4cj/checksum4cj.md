# checksum4cj

**Tag**: web, database, crypto

## 简介

Fast non-cryptographic checksums and hashes for Cangjie: CRC32, CRC32C, Adler32, FNV-1a (32/64), DJB2, SDBM, with streaming and one-shot APIs
