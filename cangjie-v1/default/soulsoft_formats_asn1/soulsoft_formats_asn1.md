# soulsoft_formats_asn1

**Tag**: library

## 简介

仓颉语言的 ASN.1 编解码库，支持 BER、CER、DER 规则，覆盖布尔、整数、字节串、OID、字符串、UTC 时间、Bit 串、SEQUENCE、SET OF 等类型，广泛用于 X.509、TLS、PKCS 等密码学场景。
