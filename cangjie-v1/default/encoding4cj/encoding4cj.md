# encoding4cj

**Tag**: library

## 简介

Cangjie port of encoding_rs v0.8.35: a semantically 1:1 implementation of the WHATWG Encoding Standard (decode/encode for all 40 encodings). Dual-licensed Apache-2.0 OR MIT; index data under WHATWG BSD-3.
