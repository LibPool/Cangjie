# prng4cj

**Tag**: library

## 简介

Deterministic pseudo-random number generators for Cangjie: SplitMix64, MT19937/MT19937-64, PCG32/PCG64, xoshiro256**/++, xoroshiro128++ with jump-ahead and unbiased bounded integers
